Setup & troubleshooting
Setup (one time, ~5 minutes):
1. Go to script.google.com → New project
2. Delete all existing code, paste everything from google-apps-script.js (in the zip)
  · Creates tabs including UTHoldings and UTNav for unit trust sync on first save
3. Click Save → Deploy → New deployment
4. Type: Web app · Execute as: Me · Access: Anyone
5. Click Deploy → Google will ask you to authorise → click Allow
6. Deploy, authorise, then use Test connection above (the web app URL is fixed in this app).

⚠️ If "Failed to fetch" appears:
· Make sure the URL ends in /exec (not /dev)
· Re-deploy: Deploy → Manage deployments → Edit → New version → Deploy
· Make sure "Who has access" is set to Anyone (not Anyone with link)

Privacy & offline use
Data stays on this device unless you turn on Google Sheets sync (your own Drive). No accounts or tracking in the app itself.
App stuck or showing an old version?
After an update, some phones keep an old offline copy and the screen may stay blank or show the wrong build number.

Use Fix stuck update below. It clears cached app files and reloads the latest version. Your expenses, income, and settings are not deleted.

Lock app now ends this unlocked session — you will enter your PIN again after reload.

Recover data on Google Sheets: if sync ever removes rows, open your Sheet → File → Version history → restore a snapshot from before the problem.

How cost/km, L/100 km, and km/L are calculated

This fill: if you enter odometer, we show km since your last reading, L/100 km, and km/L for this tank.

Date range average: choose From/To on the efficiency card, or tap Last month / All time. Only fill-ups with odometer inside the range are counted.
